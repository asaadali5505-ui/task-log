# task-log

تطبيقان عربيان يعملان في المتصفح دون خادم، ويُثبَّتان على الشاشة الرئيسية ويعملان دون إنترنت:

- **سجل المهام** (`index.html`): تسجيل المهام وحالاتها ومشاركة تقريرها عبر واتساب، مع أرشيف شهري.
- **مساعد التداول** (`trading/`): تحليل فني، حاسبة حجم الصفقة، سجل صفقات، إحصاءات أداء، واختبار استراتيجيات. التفاصيل في [`trading/README.md`](trading/README.md).
