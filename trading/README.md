# مساعد التداول

تطبيق ويب عربي يعمل على الجوال والآيباد والحاسوب، ويُثبَّت على الشاشة الرئيسية ويعمل دون إنترنت.
يساعد على **الانضباط وإدارة المخاطر**، ولا يَعِد بتوقع السوق: القراءات الفنية ونتائج الاختبار وصف لما حدث، وليست توصية.

## الأقسام

| القسم | ما يفعله |
|---|---|
| السوق | شموع يابانية مع متوسطي 20 و50 ومؤشر RSI، وقراءة فنية موزونة (الاتجاه، الزخم، التقلب، أقرب دعم ومقاومة)، ومستويات وقف وهدف محسوبة من التقلب (ATR). |
| الحاسبة | تحسب كمية الصفقة التي تجعل الخسارة عند الوقف تساوي نسبة المخاطرة المحددة، مع العائد إلى المخاطرة ونسبة النجاح اللازمة للتعادل، وقائمة تحقق قبل الدخول. |
| الصفقات | سجل للصفقات المفتوحة والمغلقة، مع تنبيه عند بلوغ حد الخسارة اليومي أو أقصى عدد صفقات في اليوم. |
| الأداء | صافي النتيجة، نسبة النجاح، معامل الربح، متوسط الصفقة بمضاعف المخاطرة (R)، أقصى تراجع، منحنى الرصيد، وتفصيل حسب الاستراتيجية والرمز واليوم وطريقة التنفيذ. |
| الاختبار | اختبار ثلاث استراتيجيات على الأسعار السابقة مقارنةً بالشراء والاحتفاظ، ومحاكاة مونت كارلو لأثر نسبة المخاطرة. |

## مصادر الأسعار

- **العملات الرقمية**: تُجلب مباشرة من واجهات عامة لا تحتاج مفتاحاً، بالترتيب: Binance ثم Bybit ثم OKX.
- **أي سوق آخر** (أسهم، فوركس، ذهب، مؤشرات): استيراد ملف CSV مُصدَّر من TradingView أو Investing أو MetaTrader.
- عند انقطاع الاتصال تُعرض آخر أسعار محفوظة، وإن لم توجد تُعرض بيانات تجريبية مولّدة مع تنبيه واضح بأنها ليست أسعاراً حقيقية.

## البيانات

كل شيء محفوظ داخل المتصفح على الجهاز نفسه (`localStorage`) ولا يُرسَل إلى أي خادم. من «الخطة والإعدادات» يمكن حفظ نسخة احتياطية واسترجاعها وتصدير الصفقات إلى CSV.

## الملفات

| الملف | المحتوى |
|---|---|
| `index.html` | هيكل الصفحة والنوافذ |
| `app.css` | التنسيق، بوضعين فاتح وداكن |
| `core.js` | الحسابات البحتة: المؤشرات، حجم الصفقة، الإحصاءات، الاختبار الرجعي، مونت كارلو، قراءة CSV |
| `charts.js` | الرسوم البيانية (SVG بلا مكتبات) |
| `app.js` | الواجهة: الحالة والحفظ وجلب الأسعار وعرض الأقسام |
| `sw.js` | حفظ ملفات التطبيق للعمل دون إنترنت |
| `tests/core.test.js` | اختبارات الحسابات |

لا توجد مكتبات خارجية ولا خطوة بناء. للتشغيل محلياً افتح `index.html` في المتصفح، وللاختبار:

```
node --test trading/tests/core.test.js
```

## حدود معروفة

- الاختبار الرجعي يستثمر رأس المال كاملاً في كل صفقة وينفّذ عند افتتاح الشمعة التالية للإشارة، ولا يحاكي الانزلاق السعري.
- آخر شمعة في الأسعار المباشرة لم تُغلق بعد، فقد تتغير القراءة الفنية حتى إغلاقها.
- الرصيد الحالي يساوي الرصيد الابتدائي مضافاً إليه نتائج الصفقات المغلقة؛ عند الإيداع أو السحب يُعدَّل الرصيد الابتدائي يدوياً.
